# 영어공부

성인 학습자를 위한 단계별 영어 학습 사이트입니다. 내 수준에 맞는 책을 골라 시작하세요.

| 책 | 이런 분께 | 주요 내용 |
|---|---|---|
| [초급 영어](beginner/index.md) | 영어를 다시 시작하는 분 | be동사, 기본 시제, 생활 어휘 |
| [중급 영어](intermediate/index.md) | 기초 문법은 아는 분 | 완료 시제, 관계사, 독해 |
| [고급 영어](advanced/index.md) | 정확하고 세련된 영어가 목표인 분 | 도치, 가정법, 글쓰기 |
| [영어 회화](conversation/index.md) | 바로 말하고 싶은 분 | 여행, 직장, 일상 대화 |

## 이렇게 공부하세요

- 예문 옆 🔊 를 누르면 원어민 음성이 나옵니다. 🐢 는 천천히 읽은 음성입니다.
- 연습 문제를 푼 뒤 **정답과 해설**을 눌러 확인하세요.
